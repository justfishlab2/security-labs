# Security and safety

## Intended use

This repository contains intentionally vulnerable teaching code. Run it only locally or in an owned, isolated environment. The mock identity header is client-controlled and is not production authentication. Do not expose the lab as a public service.

The educational defect explicitly demonstrated in `/unprotected` and the documented mock-identity limitations are intentional, not undisclosed findings.

## Reporting an unexpected issue

For an unexpected problem that exposes repository secrets, affects the deployed portfolio, or creates a risk beyond the documented lab behavior, email **hello@justfishlab.my.id**. Include the affected file/commit, a minimal synthetic reproduction, expected behavior, and observed behavior. Do not send live credentials or personal data.

Please do not publish private details in issues. For a vulnerability in a third-party service, follow that service’s policy instead; this repository does not grant permission to test it.

There is no guaranteed response SLA, bounty program, or paid reward associated with this repository. No production security or compatibility guarantee is offered for the teaching code.
